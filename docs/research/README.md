# Research log

Findings from building and running this pipeline, each kept with its evidence. Conventions:

- **Evidence** is a file in [`evidence/`](evidence/) (log excerpts with their source run,
  reports, reproducer scripts and their output), a line of ExecuTorch's source at commit
  `3dd7ccd1d863fad22639dd2d918ae34a41ce45f0` (v1.4.0; paths are relative to its repo root),
  or a test in this repo that pins the behaviour.
- **How known:** *measured* (a number from a run), *reproduced* (failure and fix shown in a
  controlled run), *source* (read in the code), *estimate* (arithmetic, shown in full).
- GitHub deletes Actions logs after its retention period, and the runs of 2026-09-12 up to
  run 5 were deleted on 2026-09-13 with the commit-history purge. Their excerpts in
  `evidence/` were cut from the logs downloaded while they still existed; the headers say
  which is which.
- A finding is never edited to fit a later result. A correction is a new entry that points
  at the old one.

## Studies
